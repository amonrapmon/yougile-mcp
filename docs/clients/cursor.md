# Подключение к Cursor

**Транспорты:** удалённый Streamable HTTP + OAuth или локальный stdio. **Статус:** пример конфигурации; E2E с нашим сервером ещё не выполнен.

## Удалённый MCP

Создайте глобальный файл `~/.cursor/mcp.json` либо проектный `.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "yougile": {
      "url": "https://YOUR-HOST.example/mcp"
    }
  }
}
```

Замените адрес реально развёрнутым HTTPS URL. Откройте настройки MCP в Cursor, подключитесь к серверу и завершите OAuth-вход в YouGile через браузер. Проверку начинайте с безопасной операции чтения.

В зависимости от режима Cursor может использовать веб-callback `https://www.cursor.com` либо локальный loopback callback. По умолчанию наш сервер разрешает loopback, но **не добавляет `https://www.cursor.com` автоматически**. Если используется веб-callback, оператор должен явно добавить проверенный origin в `CLOUD_OAUTH_REDIRECT_ORIGINS`. Не разрешайте произвольные адреса возврата.

## Локальный stdio

Следуйте [инструкции локальной установки](local-stdio.md). Cursor поддерживает запуск локального MCP через поля `command`, `args`, `env` в `mcp.json`. Укажите полный путь к установленному `yougile-mcp`, приватному файлу идентичности и передавайте API-ключ только через защищённое окружение запуска.

Официальная документация: [Cursor MCP](https://cursor.com/docs/mcp).
