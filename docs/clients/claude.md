# Подключение к Claude Web / Desktop

**Транспорт:** удалённый Streamable HTTP + OAuth. Локальный stdio у Claude Desktop является отдельным режимом и рассматривается в [инструкции локальной установки](local-stdio.md).

**Статус:** инструкция по подключению, а не подтверждение реального E2E с YouGile MCP.

## Подключение удалённого сервера

1. Откройте **Customize → Connectors** (путь зависит от версии Claude и настроек рабочего пространства).
2. Выберите добавление собственного коннектора, если оно доступно вашему тарифу или организации.
3. Укажите название **YouGile MCP** и адрес `https://YOUR-HOST.example/mcp`.
4. Используйте поддерживаемый клиентом OAuth-процесс с динамической регистрацией, когда этот вариант доступен. Наш сервер не предусматривает опубликованного статического OAuth client ID для всех клиентов.
5. Пройдите авторизацию через страницу YouGile и выберите компанию, если появится соответствующий запрос.
6. Включите коннектор в диалоге и проверьте безопасную операцию чтения.

В командных рабочих пространствах настройка коннектора может требовать разрешения администратора.

**Важно:** удалённый коннектор Claude обращается к MCP со стороны инфраструктуры Anthropic, даже если вы используете Claude Desktop. Он не может подключиться к `127.0.0.1` на сервере оператора. Требуется общедоступный HTTPS-адрес. По умолчанию сервер разрешает callback origin `https://claude.ai` и `https://claude.com`; при подключении проверяйте фактический redirect URI.

Официальная документация: [собственные MCP-коннекторы Claude](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp).
