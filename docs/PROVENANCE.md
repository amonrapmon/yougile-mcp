## Requirements before importing code

Record source URL, immutable commit SHA, owner, license, copyright notices,
relevant tests and the rationale for reuse. Update NOTICE.

If an upstream does not provide an explicit license or permission, do
not use its source implementation. A public GitHub repository is not
in itself a copyright license. Resolve PR #5 licensing in
https://linear.app/amonrapmon/issue/GEN-211.
